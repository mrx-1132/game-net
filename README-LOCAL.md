# راهنمای اجرای محلی و ساخت نسخه `.exe` در ویندوز

این فایل برای حل دقیق مشکلات نصب و اجرای برنامه روی سیستم شخصی شما (ویندوز) آماده شده است.

---

## علت خطای `lightningcss` چیست؟
خطای `Cannot find module '../lightningcss.win32-x64-msvc.node'` زمانی رخ می‌دهد که ابزار مدیریت پکیج (`npm`) در سیستم شما نتوانسته است فایل‌های باینری بومی ویندوز مربوط به پردازش استایل‌ها (`lightningcss` که توسط Tailwind CSS استفاده می‌شود) را به درستی دانلود یا نصب کند.

---

## 🛠️ مراحل حل گام‌به‌گام و قطعی مشکل

پوشه پروژه خود را در نرم‌افزار **VS Code** یا ترمینال ویندوز (`CMD` یا `PowerShell`) باز کنید و دستورات زیر را به ترتیب اجرا کنید:

### ۱. حذف فایل‌های نصبی قدیمی و حافظه کش (پاکسازی اولیه)
ابتدا دستور زیر را برای حذف پوشه `node_modules` و فایل‌های قفل اجرا کنید تا تداخل برطرف شود:
#### در CMD ویندوز:
```cmd
rmdir /s /q node_modules
del package-lock.json
npm cache clean --force
```

#### در PowerShell ویندوز:
```powershell
Remove-Item -Recurse -Force node_modules
Remove-Item -Force package-lock.json
npm cache clean --force
```

---

### ۲. نصب مجدد بسته‌ها به همراه نسخه مخصوص ویندوز (راه حل اصلی)
حالا دستور زیر را اجرا کنید تا پکیج‌های اصلی نصب شوند و سپس نسخه مخصوص ویندوز ۶۴ بیتی `lightningcss` را به صورت دستی و مستقیم نصب کنید:

```bash
# نصب پکیج‌های پروژه
npm install

# نصب مستقیم فایل‌های باینری ویندوز برای استایل‌ها
npm install lightningcss-win32-x64-msvc --save-exact
```

> **نکته بسیار مهم:** اگر کماکان خطا دریافت کردید، استفاده از مدیریت پکیج **pnpm** یا **yarn** به شدت پیشنهاد می‌شود چون بسیار در دانلود پکیج‌های اختیاری ویندوز قوی‌تر هستند:
> ```bash
> # روش جایگزین با pnpm (در صورت نصب بودن)
> pnpm install
> ```

---

### ۳. ساخت فایل خروجی `.exe` (Electron Portable)
پس از اینکه نصب دستورات بالا با موفقیت به پایان رسید، با اجرای دستور زیر برنامه را بیلد کرده و نسخه پرتابل ویندوز را بسازید:

```bash
npm run electron:dist
```

## 🌐 رفع خطای اینترنت / تحریم هنگام ساخت EXE (`winCodeSign` یا `github.com: no such host`)
ابزار `electron-builder` در اولین باری که می‌خواهد فایل `.exe` بسازد، تلاش می‌کند یک پکیج سیستمی به نام `winCodeSign` را از سرور GitHub دانلود کند. در ایران به دلیل فیلترینگ یا مشکلات DNS، خطای زیر رخ می‌دهد:
`Get "https://github.com/electron-userland/electron-builder-binaries/releases/download/winCodeSign-2.6.0/winCodeSign-2.6.0.7z": dial tcp: lookup github.com: no such host`

### راه‌حل‌های حل این مشکل:
1. **استفاده از فیلترشکن / VPN / تحریم‌شکن (Shecan/403.online)** در زمان اولین بار اجرای `npm run electron:dist`.
2. **روش دستی (آفلاین بدون نیاز به VPN):**
   - فایل فشرده `winCodeSign-2.6.0.7z` را با مرورگر از لینک زیر یا با فیلترشکن دانلود کنید:
     `https://github.com/electron-userland/electron-builder-binaries/releases/download/winCodeSign-2.6.0/winCodeSign-2.6.0.7z`
   - به مسیر زیر در ویندوز خود بروید:
     `C:\Users\نام‌کاربری‌شما\AppData\Local\electron-builder\Cache\winCodeSign`
     (اگر این پوشه وجود ندارد آن را به صورت دستی بسازید).
   - یک پوشه به نام `winCodeSign-2.6.0` بسازید و محتویات فایل ۷z را درون آن استخراج (Extract) کنید.
   - حالا دستور `npm run electron:dist` را اجرا کنید؛ بیلد سریعاً و به صورت کاملاً آفلاین انجام خواهد شد.

## 🎨 لوگو و آیکون فایل EXE و پنجره برنامه
لوگوی ارسالی شما (تیم **AT TEAM**) در مسیرهای زیر ذخیره شده و به طور پیش‌فرض برای برنامه الکترون تنظیم گردیده است:
- `public/icon.png` (آیکون پنجره، وب، تسک‌بار و فایل اجرایی)
- `electron/icons/icon.png`

اگر در آینده خواستید لوگو را تغییر دهید، کافی است فایل تصویری جدید خود را با نام `icon.png` (یا فرمت ویندوزی `icon.ico`) در پوشه `public/` جایگزین کنید.

---

## 📂 خروجی نهایی کجاست؟
پس از اتمام بیلد، یک پوشه جدید به نام **`dist-electron`** در ریشه پروژه شما ساخته خواهد شد. داخل این پوشه فایل اجرایی شما با نام:
`GameNetManager 1.0.0.exe` (یا نام مشابه) قرار دارد که بدون نیاز به نصب، تنها با دوبار کلیک اجرا خواهد شد!

---

## 💻 اجرای تستی نسخه دسکتاپ (بدون بیلد نهایی)
اگر می‌خواهید قبل از خروجی گرفتن، برنامه را رو دسکتاپ تست کنید:
```bash
npm run electron:dev
```
