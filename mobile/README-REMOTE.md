# ریموت موبایل (APK) — راهنما

## ۱) سمت کامپیوتر (برنامه Electron)
تغییرات داخل پروژه اعمال شده؛ وابستگی جدیدی لازم نیست. فقط دوباره بیلد کنید (`npm run electron:dist`).
- سرور ریموت روی پورت **4747** بالا میاد.
- ویندوز اولین بار پیام فایروال می‌دهد → **Allow** (Private network).
- داخل برنامه (با ورود ادمین) ← **تنظیمات** ← پایین صفحه بخش «📱 ریموت موبایل»: آدرس و کد ۶ رقمی (۵ دقیقه اعتبار، یک‌بار مصرف).
- بهتره برای PC آدرس IP ثابت (یا DHCP reservation در مودم) بگذارید.

## ۲) ساخت APK
پیش‌نیاز: Node، JDK 17 و Android Studio (SDK).
```bash
cd mobile
npm run setup      # نصب Capacitor + افزونه اثر انگشت + ساخت پروژه اندروید + پچ مانیفست
npm run open       # باز شدن در Android Studio → Build > Build APK(s)
```
خروجی: `mobile/android/app/build/outputs/apk/debug/app-debug.apk`
(یا خط فرمان: `cd android && gradlew assembleDebug`)
> Gradle از سرورهای گوگل/Maven دانلود می‌کند؛ در ایران احتمالاً به VPN یا mirror نیاز دارید.

## ۳) استفاده
APK را نصب کنید → آدرس `IP:4747` + کد + نام گوشی → اتصال. گوشی و PC باید روی یک وای‌فای باشند.
ثبت بدهی/پرداخت قبل از ارسال، اثر انگشت می‌خواهد.

## نکات امنیتی
- هر گوشی توکن مخصوص خودش دارد (هش‌شده روی PC)؛ از «حذف دسترسی» در پنل می‌شود لغوش کرد.
- ارتباط HTTP ساده روی شبکه داخلی است؛ فقط به وای‌فای مورد اعتماد وصل کنید.
- اثر انگشت یک قفل سمت گوشی است؛ سرور به گوشی جفت‌شده اعتماد می‌کند.
